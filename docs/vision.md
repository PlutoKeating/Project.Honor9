# 项目愿景：Amani 智能体工坊

## 我们在做什么

我们要把一台 2017 年的荣耀9改造成一个**专门给智能体用的设备**。它不再是一部供人日常使用的手机，而是智能体「Amani（神谷薰）」长期栖居的“家”：智能体通过这台设备感知环境、执行操作、积累记忆，并持续成长。

## 为什么是一台旧手机

- **单价低，性能够用**：8 核 CPU、6 GB 内存、128 GB 存储，全天运行只需要几瓦功耗。
- **能力齐全**：一台机器同时具备摄像头、麦克风、扬声器、多种传感器、Wi-Fi、蜂窝网络、NFC 和红外。
- **隔离**：设备本身就是沙箱，智能体在里面做什么都不会影响主力设备。
- **可重复**：同型号的设备随处都能买到，这里的实验方法可以复用到别的旧机器上。

## 核心原则

1. **能裁则裁**：用不到的预装应用、推送、广告、云服务和后台常驻进程，统统禁用。系统资源只留给智能体。
2. **可逆优先**：只在 shell 权限内操作，所有改动都有记录、都能回滚，不刷机，也不破坏系统分区。
3. **一切留痕**：每次实验都写明目的、步骤、结果和回滚方法。脚本放进仓库，敏感数据留在本地。
4. **AI-Native**：设备的主要使用者是智能体，不是人。交互、调度和权限都按智能体的需要来设计。

## 阶段规划

| 阶段 | 目标 | 产出 |
|---|---|---|
| 0 · 接入 | 建立稳定的 ADB 通道，给设备建档 | `docs/device/`，udev 规则 ✅ |
| 1 · 备份 | 导出应用清单和用户数据，建立基线 | `scripts/backup/`，基线清单 |
| 2 · 精简 | 分批禁用或卸载无用的应用和服务，观察系统稳定性 | `configs/packages/`，`scripts/debloat/` |
| 3 · 调优 | 常驻保活、省电策略、网络、温控、充电上限 | `configs/services/`，实验记录 |
| 4 · 环境 | Termux + runit 运行环境，打通主机和设备的通信 | `scripts/deploy/` ✅ |
| 5 · 培育 | 部署 Amani，接入感知和执行能力，形成记忆 | 子模块 `Project.Windler/`（含 Termux 身体适配器） |
| 6 · 开放 | 让任何人在一台旧安卓手机上装好 Windler、接入或创造自己的 agent | Windler App 的安装向导（子模块），本仓库退为荣耀9 特有的精简与运维 |

## 关于 Amani（神谷薰）

本仓库培育的智能体名为 **Amani**，中文名 **神谷薰**。文档、代码和目录中统一用 `amani` 作为标识符。她运行在独立仓库 [Project.Windler](https://github.com/PlutoKeating/Project.Windler) 提供的通用 Agentic 生命运行基座上（基座与具体 agent 解耦，她的名字等身份数据存放在她自己的灵魂仓库）。人格与记忆存放在私有的灵魂仓库中，由基座全自动同步；装有 Hermes Agent 或 OpenClaw 的其他设备可以通过可插拔的 soul-bridge 成为她的另一具身体。
