## Quetzal 0.6.7：Linux 家目录改为 ~/.quetzal（所有者要求）

- 所有者要求 Linux 版所有本地存储的缺省目录从 `~/quetzal` 改为 `~/.quetzal`，且必须可自定义。缺省按平台取：Termux（`PREFIX` 含 com.termux）仍为 `~/quetzal`（安卓安装器、runit 服务与开机脚本都按此约定，不改以免老手机升级后找不到家目录），其他机器 `~/.quetzal`；`QUETZAL_HOME` 环境变量与 `--home` 覆盖，垫片、启动器、守护循环都把安装时的家目录写死在脚本里，所以自定义位置全链路生效。
- 迁移：`install.sh` 与 cli 的 `install()` 都在「没有显式指定 + `~/.quetzal` 不存在 + `~/quetzal` 里有老安装」时先停服务 / 守护循环，再 `mv` 整目录，然后照常用新路径重写服务单元、垫片、启动器与 crontab 项。本机的实例按所有者要求没动，下次所有者自己跑安装命令时会自动搬。
