## Quetzal：一键安装后的七个问题——守护开关、桌面外壳四项修复、原生 Linux 控制台（所有者要求）

- 所有者试用后报了七个问题：任务栏没有 logo、每 3–6 秒闪一下「不在线」横幅、分隔线不能拖、中等宽度布局把主区挤成一条、窄屏推入聊天页后拉宽窗口残留、服务页要一个「开机自启 + 崩溃自动重启」开关、活动概览里的应用图标是齿轮。中途所有者明确要求：不得与 Edge 这种单一浏览器耦合；在我给出 A（原生控制台）/ B（Chromium 系 app id）/ C（放弃）三个选项后选了 A。
- **守护开关**：适配器接口新增可选 `supervision`，Linux 适配器操作 systemd 用户服务（关 = disable + `quetzal.service.d/quetzal-off.conf` 写 `Restart=no`，daemon-reload 后真机验证 `systemctl show -p Restart` 立即变为 no）或守护循环（`state/supervise.off` 标志暂停拉起 + 增删 crontab/自启动项），Termux 适配器操作 runit `down` 与 Boot 脚本；网关方法 `supervision` / `setSupervision`；服务页 `_SupervisionSection`。
- **离线闪烁根因**：`api.connect()` 关旧 socket 时没注销监听，旧连接迟到的 `onDone` 把新连接判为断开并再次重连，形成循环；修为状态只听当前连接。
- **桌面外壳**：`_Splitter` 可拖分隔线（宽度记 shared_preferences），`LayoutBuilder` 保证主区 ≥ 420、不够时压两侧再收起右栏并在导航栏给「此刻」按钮；`_ShellState.didChangeDependencies` 在外壳切到桌面时 `popUntil` 根路由，手机聊天页 `initState` 写 `nav`。
- **原生 Linux 控制台（方案 A）**：`flutter create --platforms=linux`，应用 id `xyz.quetzal.console`、可执行 `quetzal-console`；平台层 `caps` 改条件导入（`hasBody` 只有安卓为真、新增 `isDesktop`），桌面版连回环地址走 `GET /auth/local` 免配对（真机验证：首次启动即拿到令牌与 agent 名字）；Mermaid 在无 WebView 平台降级。`tool/build-linux.sh` 打成 `quetzal-<版本>-linux-<架构>-console.tar.gz`（13 MB）；发版工作流新增 `linux-console` job（ubuntu-22.04，glibc 更老兼容更广）。安装脚本有桌面时下载同版本包到 `~/quetzal/console/`，没有则退回浏览器（容器验证了退路）；桌面项改名 `xyz.quetzal.console.desktop`。实测发现 GTK 在 X11 下的 WM_CLASS 也是应用 id 而非二进制名，`StartupWMClass` 据此定为 `xyz.quetzal.console`。
- 本机为验证装了 clang、libgtk-3-dev、liblzma-dev；运行基座以 `releases/0.5.0-dev` 部署，原生控制台放在 `console/0.5.0-dev`，正式发版前所有者本机即可体验。教训：本机重跑安装脚本会把 current 切回 npm 包内置版本，dev 部署要手动指回。
- 待办：0.5.x 发版后 Release 才有 Linux 桌面包，一键安装的原生控制台路径届时才对外生效；所有者需在 GNOME 里确认任务栏 / 活动概览图标。
