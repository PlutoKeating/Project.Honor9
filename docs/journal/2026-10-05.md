## Quetzal：Linux 一键安装 `curl -fsSL https://quetzal.plutokeating.beer/install | bash`（所有者要求）

- 所有者希望像 Cursor / MiMo Code / Kimi Code 那样一行 curl 装好基座，并明确要求：依赖预检与自动补齐（Node 走 nvm、要装 git）、开机自启 + 崩溃自动重启且不拖慢安装的守护方案、应用列表与任务栏有 logo、CLI 界面优雅、中英双语（简繁中文显示中文）。中途特别提醒：不要以本机环境为默认生产环境，路人用户可能缺任何依赖——这条已记入长期记忆。
- 实现为子模块的 `cli/install.sh`（纯 bash 4+，官网构建时由 `website/scripts/postbuild.mjs` 原样复制为 `/install` 并写 `_headers`）：探测发行版 / 包管理器（apt dnf yum pacman zypper apk xbps）/ musl / systemd 用户实例 / 桌面 / WSL / 容器；缺的 git curl tar CA 证书用系统包管理器装（root 直装，否则 sudo/doas 向 /dev/tty 要密码）；Node 22.13+ 带 npm 的 PATH 有就用、nvm 里有就用、否则装 nvm 再 `nvm install 22`，Alpine 用 apk，NixOS 要求自备，nodejs.org 不通自动切 npmmirror；npm 包装进 `~/quetzal/npm` 独立前缀并写 `~/.local/bin/quetzal` 垫片（绝对路径 node）；守护选型：systemd 用户服务（已有）+ 确保 `loginctl enable-linger`，无 systemd 时退回几十行 POSIX sh 守护循环 + `crontab @reboot` + 桌面自启动项（零额外安装，最快）；桌面：图标取自包内 `web/icons`，`quetzal.desktop` + 启动器 `quetzal-console`（Chromium 系含 Flatpak 用 `--app --class=Quetzal --user-data-dir` 独立窗口，任务栏按 `StartupWMClass` 显示光团图标；只有 Firefox 则 xdg-open）；界面：半格字符逐像素渲染的光团横幅（与 favicon 同一径向渐变）、truecolor/256/无色与 UTF-8/ASCII 退化、转圈、日志尾巴；`--uninstall [--purge]`。
- 验证：`bash -n` + shellcheck 无警告；干净容器以管道喂 bash 跑通 debian-slim（root 无 git）、ubuntu 24.04（非 root + sudo + 假桌面，含升级重跑与 --purge）、fedora 42、archlinux、alpine 3.22（musl）；本机真机（Ubuntu 26.04 + GNOME + nvm）6 秒装完，systemd / linger / 桌面项 / Edge 独立窗口均正常，随后卸载恢复。官网 `npm run check` 通过，`build/client/install` 与源码逐字节一致。
