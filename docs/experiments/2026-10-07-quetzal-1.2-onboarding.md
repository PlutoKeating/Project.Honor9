# 实验：Quetzal 1.2.0 上手流程真机测试

日期：2026-10-07

## 目的

Quetzal 1.2.0 把上手改成「装、登录、用」三步（安装向导打开即装、装好自动请求权限、一次登录、模型只要一个 Key），并重排了「控制」页。在荣耀9 上真机验证两条路径：

1. **App 更新**：1.1.7 直接覆盖安装 1.2.0，运行基座应在后台换成新版本，不再弹出向导。
2. **首次安装**：清空 App 数据后从零打开，走完整个向导；登录时选已有的 agent（老用户的新设备）。

## 准备

- 包状态导出到 `backups/`（全部包、已禁用包、Quetzal 的版本与安装时间）。
- 测试前荣耀9 上是 1.1.7，身份是初始的「未命名的 Agent」，没有模型、没有登录同步服务，没有需要保留的数据。
- APK 从 v1.2.0 的发布下载，sha256 与发布的 `SHA256SUMS` 核对一致（文件在 `backups/apk-1.2.0/`，不入库）。
- 截图存 `logs/shots/`（不入库）；操作用 `adb shell input tap` 与 `screencap`。

## 步骤与结果

| 步骤 | 结果 |
|---|---|
| `adb install -r` 1.1.7 → 1.2.0 | ✅ 没有弹向导；打开 App 后运行基座以 `files/runtime/1.2.0/main.cjs` 启动。安装后 EMUI 没有立即拉起前台服务，打开 App 时才起来 |
| 打开后的前几秒 | ⚠ 横幅先显示「连不上…」与「启动」按钮，十几秒后自动连上（运行基座其实正在启动） |
| 新的「控制」首屏 | ✅ 模型显示红色「未设置」 |
| 首页「选择模型」入口 | ❌ 没有出现：组件是 const，首帧时还没连上就隐藏了，连上后不重建 |
| `pm clear` 后首次打开 | ✅ 直接进向导并开始安装，约 10 秒装好 |
| 权限 | ✅ 装好后系统权限弹窗自动出现，全部允许后这一步自动收起 |
| 后台运行 | ✅ 系统「忽略电池优化」弹窗允许后自动打勾 |
| 向导文案 | ⚠ 初始名字被拼进句子：「不让系统把未命名的 Agent关掉」 |
| 登录 | ✅ 申请到码与核对表情；❌ 手机上没有浏览器（系统精简时按所有者要求移除了 `com.android.browser`），「在浏览器中继续」静默无反应；⚠ 核对表情只显示了 2 个，第三个是 Android 9 没有字形的新表情 |
| 在主机浏览器里批准（选「神谷薰」） | ✅ 灵魂仓库自动接上，名字与主题色变成神谷薰；与主机直连（72ms），采用了主机的权限、预算、语音、通道、模型与 Key、语音密钥；首页不再有「尚未配置模型」 |
| 一次登录 | ✅ 「设备 → 账户」直接是已登录，不用第二次批准 |

## 发现的问题与修复（Quetzal 1.2.1）

- 首页「选择模型」卡片改为自己监听连接状态。
- 安卓刚打开 App 的头 30 秒，本机运行基座离线时显示「正在启动…」。
- 设备上没有能打开链接的应用时，自动复制链接并提示换一台设备打开或扫码。
- 向导与提示不再把初始名字拼进句子，统一说「ta」。
- 同步服务的核对表情只用 Emoji 5.0 以前的（Android 8 也能显示）。
- 账户概览去掉 agent 的长 UUID。

同一天还修了主机上桌面控制台的问题：升级后旧进程不退，要点「重新打开」才换上新版（见子模块提交）。

## 1.3.x：提醒与本机免配对码

- 荣耀9 装 1.3.0 时发现：几台设备里持心跳的主机还是 1.2.0（不认识提醒），手机上设的提醒会一条都不响。1.3.1 修复：持心跳的设备版本过旧时由跟随者自己触发。
- 荣耀9 与主机都升到 1.3.1（主机重跑一键安装脚本；桌面控制台用 `--replace` 换成 1.3.1）。
- 在荣耀9 上用英文对她说「2 分钟后提醒我喝水」（adb 只能输入 ASCII）：她调用 `reminder`，提醒文字由她写成「该喝水啦～💧」；首页「提醒」区随即出现这条；约 15 秒后同步到主机；**到点在主机（持心跳的设备）上准时发出**，时间线记「到点提醒了对方」，只发了一次。手机当时与主机断开，首页那条要等重新连上才同步为已完成。
- 主机上不带 Origin、同一系统用户向 `/auth/local` 要令牌成功：Linux 桌面版本机免配对码的修复在真实安装上生效。

## 1.4.0：升级（账号登录改为 OpenID Connect）

- 升级前包状态导出到 `backups/`；荣耀9 上是 1.3.1（versionCode 41）。
- 从 v1.4.0 的发布下载 APK 与 `SHA256SUMS`、`SHA256SUMS.sig`（`backups/apk-1.4.0/`，不入库）：用发布公钥验签通过，`commit` 行指向 v1.4.0 的提交；APK 哈希一致。
- `adb install -r` 覆盖安装成功（versionCode 42，签名证书一致）；打开 App 后运行基座以 `files/runtime/1.4.0/main.cjs` 启动，`/health` 报告 1.4.0。
- ✅ 首页在线，身份仍是「神谷薰」，不需要重新登录：1.4.0 换的是账户登录方式，已绑定的设备令牌不受影响。
- 首页「提醒」还留着 03:17 已在主机上发出的那条「该喝水啦」，要等与主机重新同步后才标为已完成（与 1.3.x 记录的现象相同）。

## 回滚

- 回到旧版本（1.1.7 或 1.3.1）：卸载后安装 1.1.7 的 APK（数据目录会清空；灵魂仓库与主机上的设置不受影响，重新登录即可接回）。
- 从账户里移除这台设备：主机控制台「设备 → 账户 → 概览」里移除 `stf-al10`。
