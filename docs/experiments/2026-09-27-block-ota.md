# 实验：删除已下载的系统更新并屏蔽自动更新（2026-09-27）

## 起因
屏幕上弹出 HwOUC（`com.huawei.android.hwouc`，EMUI 系统更新）对话框：“系统设置更新已下载……是否立即重启？”。这是一次 COTA（运营商/参数配置）更新。

## 限制
HwOUC 是受保护的系统应用：`pm uninstall` 返回 `DELETE_FAILED_INTERNAL_ERROR`，`pm disable-user` 和组件级 `pm disable` 都返回 `not allowed to disable this package`。

## 步骤（`scripts/debloat/block-ota.sh`，首次加 `clear` 参数）
1. 点击“稍后”，然后 `am force-stop`。
2. `pm clear com.huawei.android.hwouc`：清除它的私有数据，包括已下载的更新包和更新状态（结果为 Success）。
3. 设置：`global hw_system_update_auto_download=0`、`ota_disable_automatic_update=1`、`hwouc_display_night_details=0`，`secure hw_upgrade_remind=0`。
4. appops 设为 ignore：`RUN_IN_BACKGROUND`、`RUN_ANY_IN_BACKGROUND`、`WAKE_LOCK`、`POST_NOTIFICATION`、`SYSTEM_ALERT_WINDOW`。
5. `cmd netpolicy add restrict-background-blacklist <uid>`：禁止后台联网。
6. 移出用户级电池白名单。`power-no-optimize.sh` 已排除 HwOUC。
7. 撤销可撤销的权限（READ_PHONE_STATE、WRITE_SECURE_SETTINGS 等）。
8. 卸载 `com.google.android.configupdater`（Google 配置自动更新）。

`post-boot.sh` 每次开机后都会重新执行 `block-ota.sh`。

## 无法完成的部分
- `/data/cota/cloud`、`/data/update`、`/cache/recovery` 对 shell 不可读，无法确认或删除里面可能暂存的文件，需要 root。
- 系统级白名单（`system`、`system-excidle`）中的 HwOUC 条目来自系统分区配置，无法移除。

## 回滚
`scripts/debloat/block-ota.sh restore`；被撤销的权限用 `pm grant` 恢复；configupdater 用 `cmd package install-existing` 恢复。改动前的设置值保存在 `backups/hwouc-20260927/`。
