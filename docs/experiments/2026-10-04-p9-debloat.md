# 实验：华为 P9 (EVA-AL10) 第一轮系统精简（2026-10-04）

## 目的
第二台实验机 P9 接入后，在 shell 权限内尽可能裁掉与智能体无关的预装应用与后台服务，同时关闭省电优化、屏蔽系统更新，复用荣耀9 的方法并记录差异。

## 前置
- P9 只开启 USB 调试后才会枚举 ADB 接口，之前 `lsusb` 能看到 `12d1:107e` 但 `adb devices` 为空（与荣耀9 2026-09-27 的现象一致）。
- 两台手机同时连接，所有命令都通过 `export ANDROID_SERIAL=<P9 序列号>` 指定设备，仓库里的脚本都用 `adb shell -n`，会继承该变量。
- 接手时 P9 已完成开机向导，没有第三方应用，没有锁屏密码，屏幕超时已是无限。

## 备份
`backups/p9-20261004-035329/`（本地，不入库）：全部包及 APK 路径（`packages-all.txt`）、系统包、deviceidle 白名单、global / secure / system 三组设置、HwOUC 改动前的设置值。

## 步骤
1. 建档：`scripts/adb/collect-device-info.sh` → `docs/device/p9-eva-al10-profile.md`，敏感标识进 `private/`。
2. 精简：`scripts/debloat/apply.sh configs/packages/eva-al10/<清单> uninstall`，三批共 111 个包，逐批检查 SystemUI / 桌面 / 电话进程与 `logcat -b crash`。
   - `debloat-01-promo.txt`（37）：UC 浏览器、应用市场、花粉俱乐部、天际通、钱包、游戏中心、运动健康、阅读、视频、生活服务、智能家居、手表、云空间、查找手机、黄页、Google Play 服务更新器、TalkBack 等。
   - `debloat-02-apps.txt`（50）：负一屏、语音助手、全局搜索、主题、天气、名片识别、决策引擎、NLP、隐私空间、家长控制、工程菜单、日历、邮件、音乐、镜子、录音、备忘录、屏保、打印、Huawei Share 系列、指南针、使用技巧、智能识屏、HiAction、HiLink、iConnect、Nearby、Synergy、扫一扫、录屏、滚动截屏、悬浮导航、推荐系统等。
   - `debloat-03-services.txt`（24）：推送、CHR 遥测、HiView、用户体验改进、内容感知、华为定位服务与高德 FLP、Wi-Fi 评估、行为认证、TrustAgent / TrustCircle、运动识别、加密短信、FIDO、讯飞语音、GSF、Google 合作伙伴配置 / 备份传输 / 一次性初始化 / 联系人同步、Google ConfigUpdater、SmartcardService。
   - `keep.txt`：刻意保留的核心包与理由。
3. 省电：`scripts/deploy/power-no-optimize.sh`（Doze、App Standby、自适应电池关闭，94 个包进白名单）。
4. 系统更新：`scripts/debloat/block-ota.sh clear`（`pm clear` 成功，appops 中 `RUN_ANY_IN_BACKGROUND` 在 Android 8.0 不存在，报错一行，其余屏蔽项生效）。
5. `adb reboot`，开机 60 秒后检查。
6. 开机后：`scripts/debloat/post-boot.sh configs/packages/eva-al10`（本次为脚本新增清单目录参数）。

## 结果
- 包数量：196 → **85**，111 个全部返回 Success，没有受保护的包拒绝卸载（荣耀9 上 `parentcontrol` 卸不掉，P9 可以）。
- 重启后 uptime 正常、桌面 `UniHomeLauncher` 在前台、SystemUI 与电话进程都在，无 ANR。
- **EMUI 8 重启后没有重装任何被卸载的包**（荣耀9 的 EMUI 9 会重装 `/preas` 里的第三方应用），只恢复了 Doze，由 `post-boot.sh` 重新关闭。
- 可用内存：重启后 MemAvailable 约 2.9 GB（精简前约 2.3 GB）。
- `com.google.android.gms.persistent` 开机时连续崩溃 4 次（`Failed to find provider com.google.android.gsf.gservices`，因为 GSF 已卸载），随后被系统标记为坏进程不再拉起，之后不再占用资源。GMS 本身无法卸载，这个结果可以接受；如果以后需要 GMS，用 `cmd package install-existing com.google.android.gsf` 恢复。

## 与荣耀9 的差异（重要）
| 项目 | 荣耀9 (EMUI 9.1) | P9 (EMUI 8.0) |
|---|---|---|
| 开机重装 `/preas` 第三方应用 | 会 | 不会 |
| `com.huawei.parentcontrol` | 受保护，卸不掉 | 可卸载 |
| appops `RUN_ANY_IN_BACKGROUND` | 有 | 无 |
| 加密方式 | FBE | FDE（全盘） |
| 自带 TTS | 无 | `com.svox.pico` |

## 回滚
- 在 `pm list packages -u` 里仍能看到的包：`scripts/debloat/apply.sh configs/packages/eva-al10/debloat-0X-*.txt restore`。
- 已整个消失的可删除预装（`/data/hw_init`、`/cust`、`/system/delapp`、`/preas` 下的包）：`adb shell pm install -r --user 0 <APK 路径>`，路径见备份 `packages-all.txt`。
- 省电：`scripts/deploy/power-no-optimize.sh restore`；系统更新：`scripts/debloat/block-ota.sh restore`，设置原值在备份 `hwouc/settings-before.txt`。
